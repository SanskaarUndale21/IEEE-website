# Supabase + Admin panel setup

## 1. Supabase
1. Create a project at supabase.com.
2. SQL Editor > paste `supabase/schema.sql` > Run. Creates tables, locks them with RLS (no public policies),
   creates the private `payment-proofs` bucket and public `event-images` bucket, and seeds the 8 past events.
3. Project Settings > API: copy the project URL and the **service_role** key.
   The service role key is server only. Never prefix it with `NEXT_PUBLIC_`.

## 2. Admin secrets
```
node scripts/setup-admin.mjs
```
Enter the admin password (14+ chars). It prints `ADMIN_*` values and your private URL
(`/<ieee id>-<48 random chars>`). Put everything plus `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY`
in `.env.local` and in Vercel env vars (Production + Preview), then redeploy.
Rotating `ADMIN_ROUTE_KEY` changes the URL; rotating `ADMIN_SESSION_SECRET` logs everyone out.

## Security design
- Secret path: the only URL that serves the panel. `/admin`, `/sb-console`, wrong keys all return plain 404.
  If any admin env var is missing or malformed the panel simply does not exist.
- Login: IEEE ID + scrypt hashed password, constant time compare, equalised timing, lockout after 5 fails
  per IP / 50 global per 15 min, single active session (new login revokes old ones).
- Session: HMAC signed httpOnly `SameSite=Strict` `__Secure-` cookie scoped to the secret path, bound to the
  browser user agent, 4h absolute + 30 min idle timeout, server side revocable row in `admin_sessions`.
- Every admin API: signed cookie check in middleware, DB session check, same-origin check, per-session CSRF token.
- Payment proofs: private bucket, magic byte image validation (JPG/PNG/WEBP, 4 MB), random file names,
  viewed only through 2 minute signed URLs generated by the admin API.
- Strict CSP with per-request nonce on the admin page, `no-store`, `noindex`, frame denial, HSTS site wide.
- Public forms: zod validation, honeypot, origin check, per-IP durable rate limits (IPs stored salted-hashed).
- Every admin action is written to `admin_audit_log` (shown on the Overview tab).

Recommended extras: turn on Vercel Firewall rate limiting for the admin path, and keep the URL private.
